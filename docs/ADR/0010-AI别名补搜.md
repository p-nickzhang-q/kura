# 0010 AI 别名补搜: 模型只产搜索词

- 状态: 采纳
- 日期: 2026-11-10
- 相关: ADR 0008(扩域-影视库, 决策 4「不自动匹配」)、ADR 0004(翻译)

## 背景

影视库的「找建议」是**正则抽词 → TMDB 搜索 → 把握打分**。修过两轮之后(`0/25 → 20/25`,
以及发布站前缀与裸介质标记那两个坑), 一批 27 个候选能命中 19 个。

剩下的 8 个失败里, **7 个的搜索词本身是对的**:

| 盘上的名字 | TMDB 里的条目 |
|---|---|
| 60号高地之下 | 前哨 / The Outpost |
| 死神5 | 死神来了5 / Final Destination 5 |
| 开心鬼上身 | (中文名与 TMDB 索引不一致) |

这是**召回问题, 不是抽取问题**。正则只能删, 不能造同义词 —— 再上一个模型去"抽片名",
抽出来的还是「60号高地之下」, 还是 0 命中。

## 决策

1. **接 LLM, 但只让它产搜索词。** 模型输出 `{title, aliases[], year}`, 每一个都要
   拿去 TMDB 搜, 命中与否由 TMDB + 现有 `matchConfidence` 决定。模型不能直接给出
   `tmdb:movie:xxxx`, 也不参与"绑哪个"的决定 —— ADR 0008 决策 4 的不自动匹配没有变。
2. **只补 0 命中的候选。** 已经搜到的候选不再花模型调用(那一批占 ~70%)。
   一次 prompt 放 12 个名字, 模型按 `i` 下标回填。
3. **命中一律降一档, 并标记 `viaAlias`。** 名字直接对上给 `high`, 绕了一层别名的最多
   `medium`, 界面上显示「按别名 The Outpost」—— 人要知道这一条是怎么来的。
4. **失败不阻断。** 超时(20s)、模型返回垃圾、没配 key → 那批候选保持"没搜到",
   与不加 AI 时完全一样。错误进 `AliasEngine.errors`, 不抛到批量外层。
5. **默认关, 显式触发。** 界面上是一个单独的「AI 补搜」按钮, 不进普通「批量找建议」。
   理由: 这层会花钱、会慢, 而且 ADR 0008 的默认立场是"不猜"。
6. **缓存进 `translations.db`**(纯缓存, 删了重问)。key = sha256(模型名 + 文件名),
   同一个名字一辈子只问一次。

## 为什么不内置本地模型

这活儿只在"有一批没识别目录"时跑一次, 之后只有新文件。为了它往安装包里塞 1GB 的 GGUF、
并为每个平台维护 native ABI, 收益结构是错的。真要离线, 先做 Ollama 之类的 HTTP 对接
(`llm.baseUrl` 已经是一个可替换的端点), 而不是内置推理引擎。

## 实测(2026-11-10, 真 DeepSeek + 真 TMDB)

`各种电影` 14 个候选、`各种电影3` 13 个候选:

| 阶段 | 命中 |
|---|---|
| 只修正则之前 | 0 / 27(候选被误判成"散集", 根本没发搜索) |
| 修完正则两处 | 19 / 27 |
| 再加 AI 别名补搜 | **27 / 27** |

按别名救回来的(模型给的名字和 TMDB 里的中文名完全不是一回事):

```
开心鬼上身          → 开心家族        (via Hello Ghost)
60号高地之下        → 奇袭60阵地      (via Beneath Hill 60)
攒钱罗曼史          → 爱情储蓄罐      (via 티끌모아 로맨스)
疯狂初恋            → 我的野蛮初恋    (via 첫사랑 사수 궐기대회)
谁和她睡觉了        → 谁和她睡了      (via 누가 그녀와 잤을까?)
死神5               → 死神来了5
My Girlfriend Is An Agent → 特工强档  (via 7급 공무원)
```

**第一个版本是坏的**: 模型给的别名是对的, 但只命中了 2/14。两个原因:
1. `TmdbSearchHit` 只有中文本地化标题, 拿 `Beneath Hill 60` 搜回来的是「奇袭60阵地」,
   和别名对不上 → 现在命中里带上 `originalTitle`, 打分看「标题 ∪ 原名」。
2. 别名搜索带着模型给的 `year`, 而 TMDB 的 year 过滤很硬(`告白 2010` → 0 条,
   `告白` → 20 条) → 别名搜索一律不带年份, 年份只进打分。

## 后果

- 新增 `llm/ai-title.ts`; `tasks/suggest.ts` 多一个第二批;
  `BindingSuggestion` 多 `viaAlias`(同时补上漏声明的 `suspectSeries`)。
- `suggest` 现在可能发两轮搜索 + 一轮模型调用, 任务进度仍按候选数报。
- 模型给错别名不会污染库: 别名也要过 TMDB, 且最多 `medium`, 绑之前人要点确认。

## 不做什么

- 不让模型直接决定 TMDB id(会编)。
- 不对已有 `high` 命中的候选复查(白花钱)。
- 不把别名写进 `items`(那是元数据, 只能来自来源站)。
