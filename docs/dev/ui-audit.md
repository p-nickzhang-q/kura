## 已完成（0.4.4）

| 维度 | 问题 | 处理 |
|---|---|---|
| 组件状态 | `hover` / `active` / `disabled` / `focus-visible` **一个都没有** | 全部补齐：hover 改边框+底色、按下 `translateY(1px)`、禁用 0.42 透明、键盘焦点 2px accent 环 |
| 排版 | 10px ×3、11px ×5，低于 12px 可读下限 | 全部提到 12px |
| 间距 | 6px ×14、10px ×18 等非 4/8 网格值 | 19 处改为 8/12/16 |
| 圆角 | 4/6/8/10/999 五种混用 | 收敛为 `--radius-sm/md/lg/pill` |
| 色彩 | 校验器报 29 个散色 > 16 | 收敛为 13 个语义令牌 |
| 数字 | 表格数字会跳列宽 | `font-variant-numeric: tabular-nums` |
| 详情图片 | 图裸在空白里 | 改为有边界的"画框"：内边距 + 圆角 + 暗底 + 两层阴影；只给 `max-*`，小图不放大 |

校验结果：`check_ui.py audit` **0 项违规**。

## 待做（记下来，之后再动）

### 1. 工具栏没有主次（视觉中心缺失）

扫描 / 刮削 / 翻译 / 整理 / 下载图片 / 停止 六个按钮同权重，用户不知道该点哪个。
**做法**：只留一个主按钮（按当前状态推导：有待刮削→「刮削待处理」，有未识别→「扫描」），其余收进「更多」下拉。技能红线第 1 条：每页只有一个视觉中心。

### 2. 字体单调

全站一套系统字体，标题与正文没有对比。桌面工具类应用可以克制，但至少：
- `h1` 加 `letter-spacing: -0.02em`
- 建立 3 层字阶（18 标题 / 13 正文 / 12 标签），现在 12/13/14/18 四层且差别不明显

（技能建议引入 display 字体，但桌面 Electron 内置字体有限，暂不引外部字体文件。）

### 3. 触控目标偏小

按钮实际高度约 31px，低于技能给的 44px（Apple HIG，面向触屏）。
**当前判断**：桌面鼠标场景 32px 可用，不跟 44px。**若将来支持触屏，需要整体放大到 40px+，并重排工具栏。**

### 4. 空状态缺少引导

列表为空时只有一行灰字「没有条目。先扫描一个媒体库。」
**做法**：空状态给「下一步动作」按钮（扫描 / 添加媒体库），并区分"库是空"与"筛选后为空"两种文案（后者已有）。

### 5. 未做：动效

除了 `translateY(1px)` 与行 hover 过渡，没有任何动效。技能要求"动效有意义"——但同类工具类应用里，动效过多反而干扰。**决定：保持接近静态，只在状态切换处给 120–200ms 过渡。**
