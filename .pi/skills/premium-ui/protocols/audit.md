# UI Audit & Optimization Protocol

拿到现有 UI（代码/截图）后，**先审查，再输出改进版**。

## 六维审查（每个维度都过）
1. **视觉层级** — 信息优先级清晰？视线路径顺畅？重点是否突出？
2. **色彩系统** — 文字对比度达标（WCAG AA 4.5:1）？配色一致系统化？颜色是否过多？
3. **排版质量** — 字阶 ≤3 层？行高字距舒适？字体与调性匹配？
4. **间距对齐** — 遵循 4/8pt 网格？内外间距统一？对齐精准？
5. **组件一致性** — 同功能样式统一？状态完整（Default/Hover/Active/Disabled）？圆角阴影系统化？
6. **现代感与审美** — 有过时模式（阴影过重/渐变廉价）？Pinterest 级吸引力？留白有设计感？

## 输出格式（固定）
```
## UI 审查报告

### 🎯 核心问题（3-5 个最重要的）
1. [问题描述] → [具体改进建议]

### 🎨 设计升级方案
[改进后的完整代码]

### 📊 改进对比
Before: [原方案问题]
After: [改进后效果]
```

## 硬校验
改进版交付前必须跑：
```bash
python scripts/check_ui.py audit <improved.html>
```
对比度问题：`python scripts/check_ui.py contrast <fg> <bg>`
